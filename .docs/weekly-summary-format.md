# Weekly Summary Format

Use this exact structure for weekly work summaries:

```markdown
**Week 1 Work:**
@rapidrare - https://github.com/Five-Guy5/OBVS/issues/17 (BLOCKER)
@terminxtor - https://github.com/Five-Guy5/OBVS/issues/18 (BLOCKER)
@wqffies - https://github.com/Five-Guy5/OBVS/issues/19
@pyrallux https://github.com/Five-Guy5/OBVS/issues/20
@loafoftoast - https://github.com/Five-Guy5/OBVS/issues/21
```

Rules:

- Heading: `**Week N Work:**`
- One line per assigned ticket.
- Line format: `@handle - <issue URL>`, adding ` (BLOCKER)` only when the ticket blocks another ticket.
- List blocking tickets first.
- Do not include ticket titles, statuses, or commentary.
- Keep a blank line after the block.
